# GM Proxys — Extensão Chrome

Extensão oficial da [GM Proxys](https://gmproxys.com).

## Instalar

### Release (mais fácil)

1. [Baixe o .zip da última versão](https://github.com/gm-proxys/extension/releases/latest)
2. Extraia a pasta
3. Abra `chrome://extensions`
4. Ative **Modo do desenvolvedor**
5. **Carregar sem compactação** → selecione a pasta extraída

### Clone

```bash
git clone https://github.com/gm-proxys/extension.git
```

Use a pasta clonada no passo 5 acima.

## Uso

1. Ícone da extensão → aba **Perfil** → login na conta
2. Navegue normalmente; captchas aparecem no painel da extensão

- Site: [gmproxys.com](https://gmproxys.com)
- Página da extensão: [gmproxys.com/extensao](https://gmproxys.com/extensao)
- Login da extensão: [gmproxys.com/extensao/login](https://gmproxys.com/extensao/login)
